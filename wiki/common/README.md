# wiki/common/

Aufbereitetes Wissen, das für alle Verbindungen (R1/R2/R3) und Materialien
gilt.

- `normative_basis/` — verdichtete normative Anforderungen (mit Verweis auf
  die jeweilige Norm-ID aus `bibliography/sources.yaml`, Originaldatei im
  externen Quellenordner unter `common/norms/`).
- `concepts/` — Definitionen und Begriffsklärungen.
- `methods/` — aufbereitete, allgemeingültige Methodik.
- `literature/` — verdichtete Literaturübersichten, inkl. divergierender
  Positionen (siehe CLAUDE.md Abschnitt 11, Contradictions).
