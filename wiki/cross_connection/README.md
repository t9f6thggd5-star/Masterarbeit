# wiki/cross_connection/

Der einzige Ort im Repository, an dem R1, R2, R3 bzw. GL24h und GL75
miteinander verglichen oder kombiniert werden dürfen (CLAUDE.md
Abschnitt 12). Jeder Eintrag muss die verglichenen Verbindungen/Materialien
explizit benennen.

- `connection_comparisons/` — Vergleiche zwischen R1/R2/R3.
- `material_comparisons/` — Vergleiche zwischen GL24h/GL75.
- `overall_conclusions/` — übergreifende Schlussfolgerungen der gesamten
  Arbeit.
